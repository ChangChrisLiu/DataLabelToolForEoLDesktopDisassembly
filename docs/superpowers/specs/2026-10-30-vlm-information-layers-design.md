# E3D 数据集能给 VLM 提供什么信息 —— 信息层次、能力清单与补齐计划

状态：草案 v0.1（2026-10-30，控制方起草，待用户过目）。它回答用户的问题「VLM 那个更多的是我们能提供什么样的信息，
来给 VLM；整个数据集会变成一个 paper，可以用来 train 和 evaluate VLM 的能力」。规格 §8（导出与 VLM 层）定义了任务
V1–V18 和导出格式，本文不重复它，只把**我们手里的信息按层次摆出来**、说明每一层今天的完成度和缺口，并给出补齐顺序。

## 1. 一句话

同一场拆解，我们同时拥有：**四个视角的逐步图像**、**每个零件在每一帧的可见/完整掩码与状态**、**零件之间的物理关系与
拆解先后约束**、**标注员对每一帧的口头说明**。别的分割/视频数据集最多有前两层；后两层让「可供性、规划、拒答、跨视角」
这些问题有可验证的标准答案，而且边际标注成本接近零——这是论文里数据集的独特贡献（规格 §8.2 的 L2–L4）。

## 2. 信息层次（我们能提供什么）

| 层 | 信息 | 来源（库表 / 文件） | 今天的完成度 | 缺口 |
|---|---|---|---|---|

| L1 感知标签 | 每视角每帧：实例掩码（可见 + 完整 amodal）、类别（23 类，U45 后 +`cable`）、**跨步跨视角一致的实例身份**、状态（installed / removed / open / closed / plugged …）、位置（机箱内 / 台面 / 框外）、可见性（visible / 部分遮挡 / 完全遮挡 / 画框外）、**谁遮住谁**（`occluders`、层级与两两覆盖）、tiny 标记；合照里拆下零件的掩码 | `shape_keyframe`、`compiled_mask`、`frame_override`、`zorder`、`pair_override`、COCO 导出 | 扫描仪 64/66 台全部确认（D63、D64 在做）；OAK1/OAK2/RS 未开始；合照未开始 | **遮挡顺序**要按用户 Review 的说明修正（U44）；其他三个视角要标（U43 辅助）；合照要标（U45） |

## 3. 这些信息支持 VLM 的哪些能力（训练 + 评测）

能力分层沿用规格 §8.2：**L1 感知 → L2 可供性 → L3 规划 → L4 元认知**。`cli export-vlm` 今天已经实现 12 个 P0 任务
（V1 V2 V3 V4 V5 V6 V8 V10 V12 V14 V15 V16），每条样本带程序可复核的 `answer_check`，图片用不泄露步号的不透明 id。
用户点名的四类，对应如下：

| 用户说的 | 已有任务 | 建议补的任务（新） |
|---|---|---|
| 对现在状态的理解 | V2 零件状态/计数、V10 已完成了哪些动作 / 进度、V1 看到了哪些零件 | **V19 状态描述**：单帧 → 结构化状态表 + 模板渲染的自然语言描述（哪些零件还在、哪些已拆、哪些打开了），可直接做 caption / 多选评测 |
| 对未来的预测 | V6 下一步做什么（合法集合判分）、V5 现在能做哪些 | **V7 剩余计划**（规格里 P1）：从当前帧到目标（取出主板 / CPU）的合法序列；用优先级图判拓扑合法性、冗余步数、第一处违规 |
| 从 VLM 直接找到零件位置 | V8 指代定位（IoU / 点在掩码内） | **V8b 遮挡下的定位**：要求模型给出被遮挡零件的大致位置（amodal 框），并说明谁挡着它——直接用 `occluders` |
| 给前后两帧找出刚做了什么 | V3（动词、目标、工具）、V12 有无变化 | **V3b 多步差**：相隔 k 步的两帧，列出发生了的动作集合（顺序无关）；reorient 对作为「只换了视角、没动零件」负样本 |
| （我们额外能给的） | V4 能否做某动作及阻碍、V14 拒答、V15 跨视角、V16 计划找错 | **V20 遮挡推理**：「要露出 X 得先拆谁」= 遮挡顺序 ∩ 优先级图；**V21 合照识别**：合照里有哪些零件、数量、与机箱终态是否一致（规格 V17 的扩展，U45 后可做）；**V22 解释选择题**：用标注员说明生成的困难样本（「为什么这一帧 SSD 在导风罩上面」） |

训练与评测的用法（规格 §8.2 评测计划不变）：P0 零样本评测主流闭源模型 + Qwen3-VL / InternVL 系列 + 纯文本基线；
P1 人类基线 + LoRA 微调一个开源 VLM（训练集用模板问法，测试集 2–3k 条人工审核）；按能力层和推理深度分层报告；
困难负样本（同机相邻两步、同平台不同机器同一步、被遮挡零件提问、合法但没做的动作）照规格。

## 4. 论文里能写的贡献（草拟，供用户取舍）

1. 唯一同时具备「逐步多视角图像 + 实例级可见/amodal 掩码 + 状态机 + 物理约束图 + 人工解释」的拆解数据集；66 台、
   ~2 900 步、约 12 400 帧、四视角，外加零件合照。
2. 视角无关的状态机让同一问题在四个可见度不同的观测上有同一个标准答案 → 天然的可判定性 / 拒答与跨视角一致性基准。
3. 约束图 + 演示顺序 → 可供性与规划的**可验证**标签（合法集合而非唯一答案），每条样本带程序复核链。
4. 遮挡顺序与「谁挡住谁」作为显式标签，让 amodal 推理与「先拆谁」规划接上。
5. 评测套件：按能力层、推理深度分层的零样本结果 + 微调增益 + 人类基线。
