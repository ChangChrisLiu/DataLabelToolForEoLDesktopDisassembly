# 双机位视频精修器

双击 `D:\DataSet\start_video_refiner.bat`。默认打开 Desktop 7 的 58 段初筛结果，以后启动会恢复已经保存的精修工程。

## 文件位置

- 精修工程：`D:\DataSet\exports\video_refiner\desktop07.review.json`
- 上一次保存：同目录 `.json.bak` 文件；恢复时先关闭工程，将备份复制为新的 `.json` 文件，再用“打开工程”载入。
- 导出：默认 `D:\DataSet\exports\video_refined\<日期时间>\`，每次使用新目录。
- 启动日志：`D:\DataSet\.cache\logs\video_refiner.log`

本工具读取原视频和初筛 JSON，不修改它们，也不连接零件标注数据库。工程、临时文件与导出均放在 D:。一个工程同时只允许一个窗口写入。

## 1. 按原视频同步

1. 切换到 **原片同步** 页。此时左右视频可以独立定位。
2. 在 OAK 原视频里找一个明确的瞬间，例如工具刚接触螺丝，暂停。用“◀ 帧 / 帧 ▶”精调。
3. 在 RealSense 原视频里找到同一瞬间并暂停。可以用全片滑条定位，也可以输入秒数再点“跳转”。
4. 点击第一行的 **记录左右当前帧**。软件保存的是两张实际解码帧在各自原片中的时间戳。
5. 勾选 **联动预览**。以后改变 OAK 播放位置，右侧按同步映射显示对应画面。

单点关系为 `RealSense 原片时间 = OAK 原片时间 + 偏移`。软件不会用视频长度差、文件名或者剪完后的拼接时间猜同步关系。

建议在录像靠后位置再标记一对点。默认第二点只是检查，界面会显示误差；确认存在稳定漂移后，可开启“两点线性校正”。这时使用 `RS = a × OAK + b`，成对导出的 RealSense 播放时间也会映射到 OAK 的时长。录像中途断录、时间跳变或变化不均匀，需要另行分段对齐，不能用两个点完全纠正。请也抽查中间动作。

## 2. 逐段精修

- 左侧选择动作，自动跳到 OAK 原片的入点。原视频仍然完整，可以查看和扩展初筛边界之外的动作。
- **入点**：第一张保留的画面。点“用当前帧 [I]”。
- **出点**：不再保留的时间边界。点“用当前帧后沿 [O]”，眼前这张画面会包含在片段里。
- 时间轴的绿色边界可拖动；也可直接输入秒数。灰色虚线表示初筛边界，黄色线表示播放位置。
- 速度支持 0.25× / 0.5× / 1× / 2×；“循环当前片段”适合反复检查动作完整性。
- 可修改动作名和备注、拆分片段、新增片段，或者取消“保留”来排除片段。恢复初筛切点仅恢复该片段原有起止时间。
- “确认并下一段”记录人工确认。修改内容会使该片段重新成为待确认状态。
- 修改自动保存；支持撤销/重做。初筛来源和每段最初的起止点仍保存在工程中。
- 更改同步点、同步方式或 ROI 后，所有片段回到待确认状态；撤销可恢复先前的确认记录。
- 调整切点后，左侧列表保留原有顺序；导出按原片开始时间排序。清单中的片段 UID 和日志步号用于追溯对应关系。

常用快捷键（焦点不在文本或数字输入框时）：空格播放/暂停；左右键逐帧；I 入点；O 出点；S 拆分；Enter 确认并下一段；Ctrl+S 保存；Ctrl+Z/Y 撤销/重做。

预览按实际 PTS 解码；播放时为保持响应可能跳过显示帧，逐帧定位不使用平均帧率换算。两个机位的实际帧时间通常不会完全相等，这是采样时刻与帧率不同造成的。画面中的时钟始终显示本机位原片时间。

## 3. ROI

OAK 默认沿用初筛 ROI。RealSense 初始显示全画幅，需要按自己的画面框选电脑和操作区域。

点击某机位的“框选 ROI”，在完整画面拖出矩形；“ROI 数值”可输入原片像素坐标，也能恢复全画幅。“全画面”只影响预览，不取消已经保存的导出 ROI。两个机位分别设置 ROI。

## 4. 导出

点击“导出视频”，选择全部保留片段、已确认片段或当前片段。勾选双机位导出需要已有同步点；未同步时可仅导出 OAK。

每次输出到新目录，包含：

- `001_oak.mp4` / `001_rs.mp4` 等对应编号的视频。
- `manifest.json`、`segments.csv`：片段标识、动作、两个原片的起止时间、ROI、同步关系、实际输出时长。
- `project_snapshot.json`：该次导出使用的工程快照。
- `status.json`：只有 `complete` 才表示全部导出成功；失败和取消会保留明确状态和日志。

输出为无音频 H.264、30fps，便于对应播放。原片不重写；长视频仍从各自原始文件取帧。时长向上量化到一个输出帧（最多约 33 毫秒），奇数 ROI 宽高在右侧/下侧补一个像素，避免裁掉选中的画面。启用线性校正时 RealSense 会做相应时间映射，详细参数写入清单。区间超过另一机位的录像范围会拒绝导出，请修正同步或切点。

导出过程可取消；此前的导出不受影响。继续编辑只影响后续导出，正在导出的任务使用启动时的快照。

## 其他 Desktop

用“导入初筛”选择同结构的 `segments.json` 和对应的 RealSense 原视频，即可建立新工程。若移动了原片或盘符改变，使用“定位原片”重新选择。更换文件会清除同步点和确认状态，避免将旧同步关系误用到新视频。

命令行也可以指定：

```bat
start_video_refiner.bat --project D:\DataSet\exports\video_refiner\desktop08.review.json --manifest D:\DataSet\exports\video_desktop08_oak\segments.json --secondary "G:\path\Desktop8.mp4"
```

依赖：现有 `tda` 环境中的 PySide6、PyAV，以及 PATH 中的 FFmpeg。其他机器安装视频额外依赖可用 `pip install -e ".[video]"`，并准备 FFmpeg。
